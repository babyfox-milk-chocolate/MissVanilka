#  Мисс Ванилька

Лендинг кондитерской-пекарни. Одна страница, ноль фреймворков и библиотек — только HTML, CSS и один файл на ванильном JS.

**Две цветовые версии из коробки:** тёплая кофейная и сочная розовая (клубника-ваниль-малина).

---

## Запуск

```bash
python -m http.server 5178
```

- Кофейная — <http://localhost:5178>
- Розовая — <http://localhost:5178/pink.html>

Сервер нужен только чтобы браузер подтянул CSS/JS (по `file://` не сработает).

---

## Что внутри

- **Hero** — гигантская бледная «ВАНИЛЬКА», фирменный стакан и фото выпечки; при скролле контент отстаёт, а живая волна с соседними блоками наезжает поверх.
- **Меню** — карточки залипают и складываются в стопку.
- **О нас** — фото + заголовок в скруглённой рамке-«таблетке».
- **Обжарка** — ползунок «светлее ↔ темнее» меняет зерно, ноты вкуса и цифры.
- **Ритуал** — вертикальный скролл превращается в горизонтальный.
- **Галерея** — крупный заголовок и ряд фото на весь кадр.
- **Где мы** — часы работы и статус «открыто/закрыто» по реальному времени.
- **Меню-оверлей** — бургер раскрывает полный экран, а сайт «отъезжает» вглубь.

**Сквозное:** прелоадер, кастомный курсор, магнитные кнопки, зерно-шум, плавный инерционный скролл, параллакс — всё на нативном CSS и одном `requestAnimationFrame`.

Бережно к пользователю: `prefers-reduced-motion` гасит анимации, вёрстка адаптивная до телефона.

## Структура

```
index.html        кофейная версия
pink.html         розовая версия (тот же script.js, другой CSS)
styles.css        стили + палитра кофейной
styles-pink.css   стили + палитра розовой
script.js         вся интерактивность
assets/           фото (webp + png/jpg)
backup/           бэкап предыдущих версий
```

## Под себя

- **Палитра** — 10 токенов в `:root` (свой файл на каждую версию).
- **Шрифты** — там же: Unbounded (дисплей), Onest (текст), Fredoka (круглые заголовки), JetBrains Mono (подписи).
- **Фото** — заменить парой `webp + png` под тем же именем в `assets/`.
- **Часы работы** — объект `table` в `script.js` и таблица в HTML (держать синхронными).
